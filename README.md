## Tujuan
Tugas ini dibuat untuk mempelajari penggunaan fungsi, parameter, nilai kembali (`return`), dan scope dalam Python, serta menerapkannya dalam program utilitas matematika.

## Daftar File
- `latihan/01_salam.py` — Menampilkan salam dengan nama dan kelas.
- `latihan/02_luas_persegi_panjang.py` — Menghitung luas persegi panjang.
- `latihan/03_jumlah_n.py` — Menghitung jumlah bilangan dari 1 sampai n.
- `latihan/04_statistik_sederhana.py` — Menghitung nilai minimum, maksimum, dan rata-rata.
- `latihan/05_scope.py` — Memahami variabel lokal dalam fungsi.

## Cara Menjalankan Program
Jalankan perintah berikut melalui Terminal VS Code dari folder utama proyek:

